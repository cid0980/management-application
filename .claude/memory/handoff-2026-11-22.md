## Set up a new container
```
git clone --depth 1 -b stable https://github.com/flutter/flutter.git /opt/flutter
cd /opt/flutter && git fetch --depth 1 origin tag 3.47.9 && git checkout 3.47.9
export PATH=/opt/flutter/bin:$PATH
cd /home/user/management-application && flutter pub get && flutter gen-l10n
flutter analyze && flutter test      # expect: clean, 1249 passing
```
Use 3.47.9 exactly (matches pubspec.lock; 3.50.x gives 76 deprecation infos).
