## Later on 22 Nov (after the owner tried the APK) — all pushed
Owner feedback drove these; follow the same patterns for anything new:
- **No chip walls ("bubbles")**: lists are one sideways row under a typed box.
  `PickRow` (one pick, typed box narrows it), `ToggleRow` (many picks, picked
  first), `ChoiceRow<T>` (fixed choices, e.g. repair status) in shop_ui.dart.
  Buy phone, New repair, Enquiry, Product all use them.
- **No dialogs to fill something in**: `showInputSheet` + `InputSheet` /
  `PickSheet` (ui/widgets/input_sheet.dart). Dialogs only for "are you sure?"
  and save errors. Scanners are sheets too.
- **Save with a field missing** jumps to it and focuses it
  (`jumpToFirstError`, form_jump.dart; fields are found by their widget Key).
  Required fields: `FieldLabel(text, required: true)` / `FormSection(required:)`.
- **Busy**: `guardSave` shows "Saving…" via `whileBusy` (busy.dart);
  printing shows "Printing…". `LoadingWords` (loading.dart) for every
  loading state; words cycle every ~2 s.
- **Model row** = shop list + models in the shop's own records
  (`modelChoices`, model_records.dart). Storage sorts by size (1TB last).
- **IMEI camera** on New repair too; **serial scan** on Buy phone
  (`serialFromBarcode`, Apple box "S" prefix dropped); **text reading**
  (google_mlkit_text_recognition 1.0.3, photo → `codesInText`) behind
  "No barcode? Read the numbers"; web gets a stub (conditional import).
- **Page animations**: FadeForwards on Android (theme), tab roots cross-fade
  (`_tab` pageBuilder in router.dart), lists `FadeIn`.
- **App tour** (ui/tour/app_tour.dart): 15 steps over Home/Mobiles/Repairs/
  Sales/More, points at widget keys (home-today, home-actions, home-queue,
  nav-bar, mobiles-*, repairs-*, sales-*, more-<path>); offered once per phone
  (TourPrefs, shared_preferences); Settings › Help › App tour reruns it.
  Preview builds hide the offer unless `TOUR=1 tools/preview/preview_build.sh`.
- A new **native dependency**: push to the dev branch first and run the
  Build APK workflow there (workflow_dispatch) before main.
- Tests: 1282 passing at this point.
