  Check the latest run (mcp__github__actions_list list_workflow_runs) before

  *.jks, or secrets.**

**Product rules**
- **Keep the app simple.** Add things only when they improve an existing
  workflow (the time picker was fine). Declined as too big: exchange offer,
  day close/cash count, send repair outside, supplier dues. Ask before adding
  anything not requested; offer removals before additions.
- **No emoji anywhere in the app, and no symbol characters used as icons**
  (→ ↗ ★ ✓ ☆): Android draws them as colour emoji. Use Icon widgets.
  test/ui/no_symbol_icons_test.dart fails if one appears in lib/ or res/.
- **Icons with words; icon alone only where the value names itself.**
  Icon only: phone number, name, brand, model, IMEI, storage, colour.
  Icon + words: money rows, dates, warranty, supplier, ID, accessories.
  Tables in lib/ui/widgets/fact_icons.dart (factIcon = icon only,
  factLabelIcon = icon + words, fieldIcon = form box icons).
- **Buttons must look like buttons and their names must fit** (no "Send to
  the b..."). Equal actions = ActionTile/ActionTileRow (shop_ui.dart).
- No pop-up lists/dropdowns, no centred dialogs (bottom sheets via
  showInputSheet/InputSheet), no wrapped chip "bubbles" (one sideways row:
  ChoiceRow).
- A required field is refused when empty (save jumps to it, message under).
- Errors are plain sentences: plainError() in lib/data/firestore_errors.dart;
  never show Firebase/Platform text or codes. Translations of rule/error
  sentences live in lib/l10n/rule_messages.dart (kRuleTranslations).
- Every password box has a show/hide eye.
- 12-hour times on screen (formatTime12/formatDayTime in domain/common/dates.dart).
- Languages en/ta/hi: every new string goes in all three ARBs
  (lib/l10n/app_*.arb) then `flutter gen-l10n`; language_test checks Tamil

- Keep the bug list updated: docs/ai/AVOID_THESE_BUGS.md AND the separate

## Set up a new container
```
export PATH=/opt/flutter/bin:$PATH      # Flutter 3.47.9 (if missing, see handoff-2026-11-22)
cd /home/user/management-application && flutter pub get && flutter gen-l10n
flutter analyze            # expect: No issues found
flutter test               # expect: 1,478 passing (26 Nov)
```
**Rules tests (Firebase emulators)** — firebase-tools is not installed by
default: `npm i firebase-tools@15` in the scratchpad, then from the repo:
```
env -u JAVA_TOOL_OPTIONS -u _JAVA_OPTIONS -u HTTP_PROXY -u HTTPS_PROXY \
    -u http_proxy -u https_proxy -u ALL_PROXY -u all_proxy \
  <scratch>/node_modules/.bin/firebase emulators:exec --only firestore,storage \
  --project fm-shop-rules-test \
  "node test/rules/isolation.test.mjs firestore.rules && node test/rules/storage.test.mjs firestore.rules storage.rules"
```
Expect 61 + 26 passing. The env unsets matter (proxy blocks the storage
emulator's Firestore lookups -> every allowed case fails; the Java banner is
read as a rules error). `cd test/rules && npm install` once.

**Screenshots** (web preview of the real app, signed in locally with seed
data): `bash tools/preview/preview_build.sh`, serve `build/web` on :8812
(`cd build/web && python3 -m http.server 8812 &`), then
`node tools/preview/appshots.js <outdir> /route[:scroll] ...` and
`python3 tools/preview/sheet.py out.png a.png=Title ...` (COLS env). Flutter
web is a canvas: click by coordinates, not text. The preview has no bills;
to preview Reports with data, temporarily seed sales in main.dart before the
preview build and `git checkout lib/main.dart` after.

**Chart colours**: the dataviz skill's validator
(`node <skill>/scripts/validate_palette.js "<hexes>" --mode light`). Payment
method colours (UPI #1F7A4C, Cash #EBA524, Card #3A66C4, other #B04E9E) pass.
